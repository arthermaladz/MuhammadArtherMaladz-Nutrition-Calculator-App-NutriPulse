# MuhammadArtherMaladz-Nutrition-Calculator-App-NutriPulse

NutriPulse adalah web app kalkulator gizi dan pelacak asupan harian. Aplikasi dibuat sebagai satu file HTML mandiri dengan HTML, CSS, dan JavaScript.

## Menjalankan aplikasi

Buka `code.html` langsung di browser modern. Data jurnal dan preferensi disimpan secara lokal di browser.

## Isi proyek

- `code.html` — aplikasi NutriPulse.
- `DESIGN.md` — sistem desain dan panduan visual.
- `PRD-NutriPulse.md` — kebutuhan produk.
- `screen.png` — aset gambar proyek.

Nilai gizi yang tersedia di aplikasi merupakan estimasi contoh dan sebaiknya diverifikasi terhadap sumber resmi sebelum digunakan sebagai data produksi.
